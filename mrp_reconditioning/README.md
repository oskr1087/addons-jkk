# Reacondicionamiento de Fabricación

Autor: Oscar Morocho <oscar.morocho@gateway-resources.com>

Flujo: Borrador -> Generar OF -> Reacondicionando -> OF Hecha -> Reacondicionado.
El usuario selecciona producto terminado, lote, cantidad y ubicación con stock, agrega componentes opcionales y genera una OF ya confirmada. La OF consume el mismo producto/lote como base más los componentes adicionales y produce nuevamente el mismo producto/lote. La vista de la OF es la estándar de MRP para conservar Tarimas, Empaquetado, Etiquetas y demás herencias instaladas.
